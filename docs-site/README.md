# Label Lab user guide

This is the Fumadocs site for how to actually use Label Lab. Masters, layers, preview, export, the generate CLI.

```bash
# from the repository root (install this package once)
npm install --prefix docs-site
npm run dev --prefix docs-site

# or from this directory
npm install
npm run dev
```

Open http://localhost:3000 (home) or http://localhost:3000/docs (the guide).

Pages live in [`content/docs`](content/docs). The root README keeps the small technical bits: install, generate, CMYK, layout.
