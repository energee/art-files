Same editor, two shells: a local web app, and **Label Lab** on macOS, Windows, and Linux.

## Browser

From the repo root:

```bash
npm install
npm run dev
```

Open the URL Vite prints, always http://localhost:5173. If something else already holds that port, Vite stops with an error instead of moving to another one, because the desktop window only looks at 5173. Run a second browser-only copy with `npx vite --port 5174`.

The label is already on screen, type on bare stock, until you drop a texture. Type and the preview keeps up.

## Desktop (Label Lab)

Same UI, native menus, real open/save dialogs, and double-click for `.label` files.

A development window wants Node.js plus a stable Rust toolchain. On macOS: `xcode-select --install`. On Linux: the WebKitGTK dev packages.

```bash
rustup toolchain install stable
npm run desktop:dev
```

`npm run desktop:build` drops the installer in `src-tauri/target/release/bundle/`. macOS gets a `.app` and a DMG, Windows an NSIS `setup.exe`, Linux an AppImage (Debian 13 "trixie" and newer). Local Mac builds are ad-hoc signed. Shipping to other Macs without Gatekeeper yelling means Apple signing and notarization.

Double-click a `.label` and it opens in Label Lab, even if the app is already running. New tab, or it focuses the tab that already has that file. On Linux the association shows up once the AppImage is desktop-integrated. `Label_Lab.AppImage path/to/file.label` works either way.

Published builds check GitHub Releases after launch and when the window comes back. **Label Lab → Check for Updates…** is the same check, on demand. Dev builds skip it. They have no release key.

## Your first document

An untitled tab brings back the last master you applied (File → Open Master, Save Master, or the picker) — the layers and their positions, not that beer's name or art. Never applied one? You get the shipped Lolev template.

Give it five minutes:

1. Check the master at the top of the left sidebar.
2. Drop a rock texture on the window (PNG, JPEG, or WebP). Optional: drop a metallic mask PNG on the right half of the overlay.
3. Click **Name** in the Layers list and type this beer.
4. ABV, UPC, description, the rest, from the inspector.
5. File → Export → Export PDFs once the label is valid.

<Callout title="Still looking at bare stock?">
  Until a texture is loaded, a hint sits under the preview: drop one anywhere. Your type is already drawing.
</Callout>
