## Download Label Lab

Download the installer for your computer from [GitHub Releases](https://github.com/energee/art-files/releases): a DMG for macOS, `setup.exe` for Windows, an AppImage for Linux (Debian 13 "trixie" and newer). Published Mac builds are ad-hoc signed and Windows builds unsigned for now, so Gatekeeper or SmartScreen may warn the first time you open it.

Label Lab also runs in a browser at [https://energ.ee/art-files/app/](https://energ.ee/art-files/app/), updated with each release. On a phone or tablet it has the same menus. Open and save go through the browser's own file picker and downloads, and the master library is kept in that browser.

To run it from source instead, see the [README](https://github.com/energee/art-files#develop).

Double-click a `.label` and it opens in Label Lab, even if the app is already running: the window comes to the front, even from minimized. New tab, or it focuses the tab that already has that file. On Linux the association shows up once the AppImage is desktop-integrated. `Label_Lab.AppImage path/to/file.label` works either way.

Published builds check the configured update feed after launch and when the window comes back. On macOS, **Label Lab → Check for Updates…** requests a check on demand. On Windows and Linux, use **Help → Check for Updates…**. An update found by an automatic check appears in the status bar; when you're already up to date the status bar stays empty, and only a check you asked for says so. **Restart Now** (or **Install and Restart** on Windows) first walks any unsaved tabs the way quitting does, and Cancel there keeps Label Lab running. If an install fails, **Try again** installs the same update again. Development builds do not receive automatic updates.

## Your first label

An untitled tab brings back the last master you applied (File → Open Master…, Save Master…, or the picker) — the layers and their positions, not that beer's name or art. Never applied one? You get the built-in **Starter** master: name, style, ABV, volume, description and the government warning, with no logo or brand. Given a `.master` file for your brand? Open it once (File → Open Master…); the library remembers it.

1. Check the master at the top of the left sidebar (see [Masters and labels](/docs/masters-and-labels#master-picker)).
2. Drop a rock texture on the window (PNG, JPEG, or WebP). While you drag, the preview splits into two drop zones: left for the background, right for the metallic mask. Optional: drop a metallic mask (PNG or WebP) on the right half. See [Dropping texture and mask images](/docs/files#dropping-images).
3. Click **Name** in the [Layers](/docs/layers) list and type this beer.
4. Fill ABV, style, description and the rest from the [inspector](/docs/inspector).
5. File → Export → [Export PDF](/docs/export) once the label is valid. The print file contains the artwork and a White Ink spot layer; [inspect it in Acrobat](/docs/export#white-ink-in-the-print-pdf) with Overprint Preview enabled.
