Pick a layer in the list or on the preview and the right-hand inspector opens. Esc or a click on the empty pasteboard clears the selection and shuts it. One panel at a time. Esc inside a field, an on-preview text edit, or a drag only cancels that; the inspector stays open.

mm / pt in the inspector is display only. Under the hood it's still PDF points.

## Header

Kind icon, inline rename, enabled, locked. Same switches as the list row.

## Content

Depends on the kind:

- **Text.** The WYSIWYG editor ([Editing](/docs/editing)). Number layers (ABV) are a number box. Code-as-text layers validate like a barcode.
- **Image.** Drop or pick a file. SVG logos take the slot's fill. Rasters print as you authored them.
- **Barcode.** The code string, plus a choice list if the master offers tiers.
- **QR.** A **Link** box and a **followed by** picker of text layers (or “nothing”). The selected text is made safe for a link. Lolev ships as `https://lolev.beer/beer/{name|slug}`; that derived URL is what gets encoded.

## Typography (text)

- Font: Poppins or Barlow Condensed, or the master default
- Size in points, and **printed character height** in millimetres (tallest letter or numeral at export size)
- Align: left, centre, right, justify. A last or only justified line falls back to left
- Wrap width. Blank means no wrap
- Line spacing and heading scale
- Letter spacing (tracking)
- **Uppercase.** Display only. Stored text keeps its typed case so `{name|slug}` still reads the original

## Geometry

Position is measured from the layer's guides and anchors. **Bind** a layer to another layer's edge with a gap and it rides along when the other grows (the collab block is built this way). **Unbind** writes the current top as a plain coordinate. A layer that another visible layer is bound to can't be switched off on its own — switch off (or unbind) the layers bound to it first, or together with it.

Text and codes can rotate **90°** (reads bottom to top). Images can't.

Image layers also have width, optional height, contain/cover fit, scale, and "tint raster" for colouring a bitmap with the fill. Page art (texture and mask) always covers the page.

Barcodes: UPC-A, EAN-13, or Code 128. Module width, bar height, show digits. You'll see a warning when the module is too skinny for curved metal.

QR: square size, style (square, rounded, dots), and error correction (L, M, Q, H; default L).

## Colour

- **Fill.** Colour picker (screen eyedropper on Chromium), hex field, and **no ink**, except on barcodes and QR. Those have to scan.
- **Metallic.** On knocks out of the white-ink plate (bare stock). Off lays white ink under it.
- **Stroke.** Optional outer stroke with its own colour, metallic flag, and width in px at 600 DPI (15px = 1.8pt). The physical width holds at any export DPI. Codes default the halo to white. Everything else defaults a dark keyline.

## Override badges

A **filled dot** means an enabled variant sets this property. A **ring** means this label overrides it. Each badge resets only its own source, so clearing your beer's edit cannot rewrite the shipped variant.

## Fill contract

This is what someone filling the layer is allowed to put in. It belongs to the master and shows up in Save Master review:

- Field label (caption above the fill widget)
- Choices (a list you can pick from; typing something new is still allowed and can be learned)
- Placeholder on empty text
- Suffix after a number (`% alc by vol` and friends)
