Pick a layer in the list or on the preview and the right-hand inspector opens. Esc or a click on the empty pasteboard clears the selection and shuts it. One panel at a time. Esc inside a field, an on-preview text edit, or a drag only cancels that; the inspector stays open.

With several layers selected, the inspector edits only the last one you picked and says so ("Editing Brand only (3 selected)"). Drag, reorder and Delete still act on the whole selection.

The mm / pt toggle (**Lengths in**, under the Enabled and Locked switches) is shared by every layer and is display only. Under the hood it's still PDF points. It converts X, Y, binding gap, width, height, wrap width, barcode module width and QR size. Type size and letter spacing stay in points, stroke width in pixels and character height in millimetres; hover a field's unit to see why.

## Header

Kind icon, inline rename, enabled, locked. Same switches as the list row.

A layer that only a variant adds reads **Off** while that variant is off for this label, with a note naming the variant. Edits to it don't apply until it is on; turning it on switches the variant on too.

**Locked** is canvas-only: drag, resize and nudge are off, but values typed here still apply.

## Content

Depends on the kind:

- **Text.** The WYSIWYG editor ([Editing](/docs/editing)). Number layers (ABV) are a number box that takes plain decimals (`6`, `6.5`, `-1`), not `1e1` or `6.`; blank counts as not filled yet. Code-as-text layers validate like a barcode.
- **Image.** Drop or pick a file. SVG logos take the slot's fill. Rasters print as you authored them.
- **Barcode.** The code string, plus a choice list if the master offers tiers. A UPC-A can be typed as printed (`0 36000 29145 2` or with hyphens); it is stored as bare digits. A wrong check digit says which digit it should be.
- **QR.** A **Link** box and a **followed by** picker of text layers (or “nothing”). The selected text is made safe for a link. Lolev ships as `https://lolev.beer/beer/{name|slug}`; that derived URL is what gets encoded.

## Typography (text)

- Font: Poppins or Barlow Condensed, or the master default
- Size in points, and **printed character height** in millimetres (tallest letter or numeral at export size). The ⓘ beside Characters per inch explains what the measurements count. A warning names any character the layer's font cannot print; export refuses those until they are replaced or the font changes
- Align: left, centre, right, justify. A last or only justified line falls back to left
- Wrap width. Blank means no wrap
- Line spacing and heading scale
- Letter spacing (tracking)
- **Uppercase.** Display only. Stored text keeps its typed case so `{name|slug}` still reads the original

## Geometry

Position is measured from the layer's guides and anchors. **Bind to layer…** ties a layer to another layer's edge with a gap and it rides along when the other grows (the collab block is built this way). **Unbind** writes the current top as a plain coordinate. A layer that another visible layer is bound to can't be switched off on its own — switch off (or unbind) the layers bound to it first, or together with it.

Text and codes can rotate **90°** (reads bottom to top). Images can't.

Image layers also have width, optional height, contain/cover fit, scale, and "tint raster" for colouring a bitmap with the fill. Page art (texture and mask) always covers the page, so it has no Position fields.

Barcodes: UPC-A, EAN-13, or Code 128. Module width, bar height, show digits. You'll see a warning when the module is too skinny for curved metal.

QR: square size, style (square, rounded, dots), and error correction (L, M, Q, H; default L).

## Colour

- **Fill.** Colour picker (screen eyedropper on Chromium), hex field, and **no ink**, except on barcodes and QR. Those have to scan. Colours are 3- or 6-digit hex (`#fff` reads as `#ffffff`); a hand-edited `.label` or `.master` with a named colour such as `gold` is refused on open, naming the layer.
- **Metallic.** On knocks out of the white-ink plate (bare stock). Off lays white ink under it. Raster images (PNG, JPEG) always print on white ink, so their inspector has no Metallic toggle; use an SVG for metallic art.
- **Stroke.** One reset badge: beside the switch while the stroke is off, beside its colour while it is on. Optional outer stroke with its own colour, metallic flag, and width in px at 600 DPI (15px = 1.8pt). The physical width holds at any export DPI. Codes default the halo to white. Everything else defaults a dark keyline. A barcode can also turn on **Solid background**: the stroke colour fills the whole barcode box, quiet zone included, instead of only outlining the bars and digits.

## Override badges

A **filled dot** means an enabled variant sets this property. A **ring** means this label overrides it. Each badge resets only its own source, so clearing your beer's edit cannot rewrite the shipped variant.

## Fill contract

**Template field settings**, folded at the foot of a text layer's inspector. This is what someone filling the layer is allowed to put in. It belongs to the master and shows up in Save Master review:

- Field label (caption above the fill widget)
- **Input**: Rich text, Number, or Code. Number makes the fill a number box; Code validates it like a barcode, with its **Symbology**
- **Minimum** and **Maximum** for a Number input (blank means no limit)
- Choices (a list you can pick from; typing something new is still allowed and can be learned)
- Placeholder on empty text
- Suffix after a Number or Code value (`% alc by vol` and friends)
