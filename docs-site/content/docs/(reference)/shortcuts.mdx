---
title: Keyboard shortcuts
description: Menus, views, canvas, palette
---

Single-key shortcuts stand aside while a text field, menu, dialog, or dropdown
has focus. `⌘` shortcuts work everywhere, even while typing in a field, except
Undo and Redo, which undo the field's own typing there.

## File and edit

| Action | Keys |
| --- | --- |
| New tab | `⌘N` |
| Open project | `⌘O` |
| Close tab | `⌘W` |
| Save project | `⌘S` |
| Save project as | `⇧⌘S` |
| Export PDFs | `⌘E` |
| Export PSDs | `⇧⌘E` |
| Undo | `⌘Z` |
| Redo | `⇧⌘Z` or `⌘Y` |
| Command palette | `⌘K` / `Ctrl+K` |

On Windows and Linux, `⌘` is `Ctrl`.

## View

| Action | Keys |
| --- | --- |
| Preview: Label | `1` |
| Preview: Mask | `2` |
| Preview: Can | `3` |
| Rulers | `R` |
| Guides | `G` |

## Canvas

| Action | Keys |
| --- | --- |
| Nudge selection | Arrow keys (1 pt) |
| Coarse nudge | `⇧` + arrow (10 pt) |
| Remove selected layer | Delete / Backspace (from the Layers list) |
| Close inspector | Esc (when no field is being edited) |
| Pan | Right-button drag |
| Zoom | Scroll or pinch. Type a % in the status bar |

Open Master, Save Master, and Settings live in the menus and the palette. New Variant is in the palette and at the foot of the master picker, not the menus. None has a dedicated key.
