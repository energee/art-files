---
title: Keyboard shortcuts
description: Menus, views, canvas, palette
---

Shortcuts stand aside while a text field, menu, dialog, or dropdown has focus.

## File and edit

| Action | Keys |
| --- | --- |
| New tab | `⌘N` |
| Open project | `⌘O` |
| Close tab | `⌘W` |
| Save project | `⌘S` |
| Save project as | `⇧⌘S` |
| Export PDFs | `⌘E` |
| Export PSDs | `⇧⌘E` |
| Undo | `⌘Z` |
| Redo | `⇧⌘Z` or `⌘Y` |
| Command palette | `⌘K` / `Ctrl+K` |

On Windows and Linux, `⌘` is `Ctrl`.

## View

| Action | Keys |
| --- | --- |
| Preview: Label | `1` |
| Preview: Mask | `2` |
| Preview: Can | `3` |
| Rulers | `R` |
| Guides | `G` |

## Canvas

| Action | Keys |
| --- | --- |
| Nudge selection | Arrow keys (1 pt) |
| Coarse nudge | `⇧` + arrow (10 pt) |
| Remove selected layer | Delete / Backspace (from the Layers list) |
| Close inspector | Esc |
| Pan | Right-button drag |
| Zoom | Scroll or pinch. Type a % in the status bar |

Open Master, Save Master, Settings, and New Variant live in the menus and the palette. No dedicated keys.
