## Projects (`.label`)

File → **Save Project** (`⌘S`) / **Save Project As…** (`⇧⌘S`) writes a zip named from the beer. `<slug>.label`: lowercase, punctuation to dashes, same slug rule as the QR. Inside: the label JSON plus embedded art (texture, mask, image-layer files).

On Chromium and in the desktop app, Save is a real dialog and later Save rewrites that file in place. Everywhere else it falls back to a download.

File → **Open Project…** unpacks a `.label`. If the master it names is already in your library, that template is used. Otherwise the file's `masterHint` is tried, but only when it points inside the label's own folder or the folder of a master already in your library; a hint anywhere else is not read. When no master is found, a dialog titled “This label was made with a different master” asks what to do: **Use “…”**, which names the tab's current master, opens it on that master (as last saved), **Locate .master…** to pick the file (it joins your library; if it can't be read, the error says why), or **Cancel**. Values that no longer match the master sit on a **bench** (dormant) instead of getting dropped, so a rebind can bring them back.

Double-click a `.label` on desktop and it opens in Label Lab. Details in [Getting started](/docs/getting-started).

Drop a `.label` anywhere on the window and it opens the same way: in the current tab if you haven't touched it, otherwise a new one. A dropped file has no save target, so its first Save works like Save As. Other files the app doesn't take (a PDF, an SVG outside an image field) are ignored.

## Masters (`.master`)

Also a zip: `master.json` plus the same asset layout. Legacy JSON-only `.master` files still open.

File → Open Master / Save Master / Save Master As lives under [Masters and labels](/docs/masters-and-labels).

## Dropping images

PNG, JPEG, or WebP dropped **anywhere** in the window opens the background/mask chooser:

- Left half (or any JPEG): **texture**
- Right half, PNG or WebP: **mask**

Dropping on an inspector image field wins and loads that field. Clicking a field still opens its picker.

Background takes PNG, JPEG, or WebP. The mask takes PNG or WebP. The project file keeps the image you dropped, WebP included. Only the PDFs get a PNG copy of a WebP, because the PDF embed handles PNG and JPEG only.

A PNG mask is embedded as-authored, no recoloring. A JPEG aimed at the mask half of the chooser lands on the background instead.

## Older configs

JSON configs from the pre-rewrite UI still open and migrate. Named fills (`gold` / `white` / `black`), a `qrData` field, missing stroke layers: they pick up current defaults so historical files print like they always have.
