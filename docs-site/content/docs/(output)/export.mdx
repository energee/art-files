File → Export, the palette, `⌘E` and `⇧⌘E`:

| Action | Files |
| --- | --- |
| Export PDFs | `{name}.pdf` and `{name}-mask.pdf` |
| Export PSDs | `{name}.psd` and `{name}-mask.psd` |
| Export PDFs As… / Export PSDs As… | the same pair, somewhere new |

Each export writes both plates. In the desktop app:

- **The first export in a tab** asks where to save the art file. The dialog opens in the folder of the tab's `.label`, named after it (`Lupula.label` suggests `Lupula.pdf`). An unsaved label suggests the beer name instead.
- **The mask** goes beside the art file as `{chosen name}-mask.pdf` (or `.psd`), with no second dialog. Confirming the art file confirms the pair, so an old mask with that name is replaced.
- **Every later export of that kind in the tab** rewrites the same two files with no dialog. The header names both files it wrote.
- **Export PDFs As… / Export PSDs As…** ask again, opening on the current file, and the tab remembers the new place from then on.

The tab remembers its PDF and PSD files separately, until it closes, quits, or opens another label. In a browser each file still has its own save dialog or download.

Export greys out while the label is invalid. The reason sits in the header next to the menus. Click it, or press `⌘E` / `⇧⌘E`, to select and inspect the first invalid layer. The Layers list marks every invalid layer with a red dot.

Exports don't wait for the preview: you can export as soon as a label opens.

When an export finishes, the header names the files it saved, and screen readers announce it. The note clears on your next edit, since the files no longer match the label. An export you edit during shows no note, because its files hold the label as it was when the export began.

Exports rebuild from the full-size assets. PDFs preserve vector geometry and embed uploaded images at their original resolution. **Settings → PSD resolution** controls PSD raster resolution (default 600 DPI). Live preview uses downscaled images.

The filename is the beer name, slugged like the QR. The PDF title is `{Name} label art` (and the mask equivalent).

Both PDFs declare their printer boxes: the **TrimBox** is the 8 × 5in die, centred in the bleed, and the **BleedBox** is the whole page. The PDF **Producer** names the Label Lab version that built it.

## White-ink plate

The mask PDF is what the printer uses for white ink:

- **Blue** = white ink
- **White** = knockout (silver / metallic stock shows through)

Uploaded masks are embedded as-authored. The 3D preview classifies pixels by brightness for its metalness map (bright/unsaturated = foil, any ink colour = matte white ink). That's preview only.

No mask uploaded? The plate floods full blue. Print as a white label. Metallic elements still knock back out to bare stock on top of the flood.

Each element has a **fill** (drawn in the art PDF; `none` for no ink) and a **plate** (metallic knocks out of the white layer; white gets a white-ink underlay). Outer strokes have their own independent plate. White-ink runs inside a text line (`_white ink_` / the White ink underlay toggle) follow the same rule per span.

Barcodes ship as near-black bars inside a white halo over white ink. The white-ink plate follows that halo: each bar, and each digit's own outline, so the mask matches the stroke. Where the halo is wider than the gap between bars it closes into one shape. Solid background, off unless the layer turns it on, fills the barcode box with the stroke colour.

Export checks the code each barcode will actually print, after any `{layer}` refs expand, wherever it came from: this label, a variant, or the master. A code that isn't valid for the barcode's symbology blocks export with an error instead of leaving the barcode off. A blank or switched-off barcode doesn't block anything.

This includes a barcode cleared in the label's Code field (or values JSON), and a layer disabled by a variant or label override. Whitespace-only codes count as blank. Re-enabling a nonblank invalid code restores the export error.

## Photoshop

Export PSDs is the editable handoff. Text becomes type layers. Logo and QR become vector shapes. Outer strokes are layer effects. The description is one type layer with style runs. The barcode is one merged shape (bars plus digit outlines), not editable type.

The PSD declares the export resolution (600 ppi unless you change Resolution in Settings), so Photoshop, Preview and Finder all show it at the label's print size.

Photoshop may prompt to **Update** text layers on open. ag-psd writes the text data without a rendered bitmap. Choose Update.

The mask PSD mirrors the mask PDF: a knockout base, the recolored mask raster (or a solid white-ink flood), then every element by its plate.

The PDFs are still what you send to the printer.

## CMYK

The app outputs RGB. Before you send it:

```bash
brew install ghostscript   # once
tools/to-cmyk.sh LABRADORITE.pdf LABRADORITE-mask.pdf
```

The script preserves the PDF's authored page orientation. Conversion is not scan certification: verify the exact QR and barcode payloads on the converted artwork and on the printer's proof/stock. The shipped dots QR encodes at error correction Q, the level at which its keylined gold dots decode for ordinary names (at L most names failed a digital decoder). Changing approved QR artwork still requires the printed-label scan approval.
